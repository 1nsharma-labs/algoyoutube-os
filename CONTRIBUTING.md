# CONTRIBUTING TO ALGOYOUTUBE OS

Welcome to the AlgoYouTube OS Open-Source Community!

## Two-Way Development Model
This platform operates under a dual-engine development lifecycle:
1. **Source A (Autonomous AI Engine):** The AI Coder and Evolution Engine continuously discover open-source technologies, run benchmarks, maintain docs, and prepare PRs.
2. **Source B (Human Engineering):** Project Owner (`1nsharma`), maintainers, and community contributors contribute code, prompts, models, and connectors. The system automatically detects, tests, and incorporates human changes without overwriting them.

## Pull Request Guidelines
1. Fork the repository and create a descriptive feature branch (`feature/`, `engine/`, `connector/`).
2. Adhere to TypeScript strict mode and ESLint/Prettier configurations.
3. Add unit and integration tests under `tests/`.
4. Ensure no proprietary or paid-only dependencies are introduced.
5. Update `TASK_REGISTRY.md` and documentation accordingly.
