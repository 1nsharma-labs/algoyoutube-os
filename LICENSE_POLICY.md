**Platform:** AlgoYouTube OS  
**Default License:** MIT License  
**Authorized GitHub Organization:** 1nsharma-labs (Owner: 1nsharma)  

---

## 1. Core Principles
1. **Free by Design:** The core platform and all foundational modules are 100% Free and Open-Source Software (FOSS).
2. **Zero Mandatory Paid Subscriptions:** No mandatory closed-source API subscriptions, paid workflow SaaS, or commercial licenses are required to run, build, or deploy the platform.
3. **Strict OSI Compliance:** All runtime dependencies must carry OSI-approved or FSF-free licenses (e.g., MIT, Apache 2.0, BSD-2/3-Clause, ISC).
4. **Copyleft Boundary Enforcement:** Strong copyleft dependencies (GPL-3.0, AGPL-3.0) must run as isolated microservices or CLI binaries (e.g., FFmpeg) rather than statically linked libraries, preserving the MIT license of original AlgoYouTube OS code.
5. **Model Weight License Auditing:** Open-weight models (Llama 3, Mistral, Gemma, Phi, Qwen, DeepSeek) are explicitly cataloged in `MODEL_LICENSE_REGISTRY.json` with their exact commercial terms.
